    Read-only — the file is never modified

    Your files stay yours

    Most online PDF sites upload your document to their servers to process it. PDF Toolkit doesn’t: every merge, split, and rotation happens in JavaScript running on your machine. You can load this page, disconnect from the internet, and keep working — that’s the whole point.

    Page selectors, explained

    Tools that take page numbers all use the same simple syntax: 3 is a single page, 2-4 is an inclusive range, and 1-3,5,7-8 combines both. Page numbers start at 1. A reversed range like 4-2 counts backwards — handy for reversing a document with the Reorder tool.

    Big files welcome

    Because nothing is uploaded, there’s no upload limit and no waiting on someone else’s server. Processing speed depends only on your device; documents with hundreds of pages are typically done in a few seconds.

    Prefer a terminal?

    This app is the browser companion to the open-source pdftoolkit command line, which adds text extraction, image extraction, and compression, and scripts nicely in batch jobs. Same page-selector syntax, same offline philosophy.

    Frequently asked questions

    Is it really private? How can I check?

    Yes. Open your browser’s developer tools on the Network tab and run any operation — you’ll see no requests carrying your file. You can also load the page once, switch off your connection, and everything still works. The source code is public.

    Does it work with password-protected PDFs?

    No. Encrypted PDFs are detected and refused with a clear message rather than silently producing broken output. Decrypt the file with the password owner’s tools first.

    Will merging or splitting reduce quality?

    No. Pages are copied structurally — text, images, and vector graphics are moved as-is, never re-rendered or recompressed.

    Is there a file size limit?

    Only your device’s memory. There is no artificial cap and no “premium” tier — the app has no server to pay for.

    Can I use it offline or install it?

    Yes. After your first visit the app is cached and works without a connection. On most browsers you can also install it from the address bar (“Install app” / “Add to Home Screen”) and it opens like a native app.
